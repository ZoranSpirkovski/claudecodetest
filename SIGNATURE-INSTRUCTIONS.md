# How to Install Your Email Signature in Gmail

## Step-by-Step Instructions:

1. **Open the HTML file in a web browser:**
   - Right-click on `email-signature.html`
   - Select "Open with" → Choose your web browser (Chrome, Firefox, Safari, etc.)
   - You should see your formatted signature, NOT code

2. **Copy the rendered signature:**
   - Once the browser shows the formatted signature
   - Select ALL the content (Ctrl+A or Cmd+A)
   - Copy it (Ctrl+C or Cmd+C)

3. **Add to Gmail:**
   - Go to Gmail settings (gear icon → "See all settings")
   - Scroll down to the "Signature" section
   - Click "Create new" to add a signature
   - Paste the signature (Ctrl+V or Cmd+V) into the signature box
   - Make sure "Insert signature before quoted text" is checked
   - Scroll down and click "Save Changes"

## Troubleshooting:

- **If you see HTML code instead of formatted text:** You opened it in a text editor. Close it and open with a web browser instead.
- **If images don't show:** Gmail may block external images initially. You can allow them in Gmail settings.
- **If formatting is lost:** Try using Chrome browser and copying again.
