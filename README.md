# ✨ Professional Email Signature Generator

A beautiful, interactive web tool for creating professional email signatures without writing any HTML code.

## 🚀 Try It Now

Simply open `signature-generator.html` in your web browser and start creating!

## ✨ Features

- **Live Preview** - See your signature update in real-time as you type
- **5 Beautiful Color Themes** - Professional, Dark, Modern, Elegant, and Minimal
- **Social Media Integration** - Add Twitter/X, Telegram, LinkedIn, GitHub links with icons
- **One-Click Copy** - Copy directly to clipboard and paste into your email client
- **Download HTML** - Save your signature as an HTML file
- **Easy Instructions** - Built-in guide for installing in Gmail, Outlook, and Apple Mail
- **No Dependencies** - Pure HTML, CSS, and JavaScript - works offline!

## 📝 How to Use

### Creating Your Signature

1. Open `signature-generator.html` in any modern web browser
2. Fill in your information:
   - Name and job title
   - Email and website
   - Optional credentials/tagline
   - Social media links (only filled links will appear)
3. Choose your favorite color theme
4. Watch the live preview update instantly

### Installing in Your Email Client

#### Gmail
1. Click "Copy to Clipboard" in the generator
2. Go to Gmail Settings (⚙️ → "See all settings")
3. Scroll to "Signature" section
4. Click "Create new"
5. Paste your signature (Ctrl+V / Cmd+V)
6. Save changes

#### Outlook
1. Click "Download HTML" and open the file in your browser
2. Select all (Ctrl+A / Cmd+A) and copy
3. In Outlook: File → Options → Mail → Signatures
4. Click "New" and paste your signature
5. Click OK to save

#### Apple Mail
1. Click "Download HTML" and open in Safari
2. Select all and copy
3. Mail → Preferences → Signatures
4. Click "+" and paste
5. Close to save

## 🛠️ Technical Details

- Pure vanilla JavaScript - no frameworks required
- Responsive design - works on desktop and mobile
- Modern CSS Grid layout
- Clipboard API for seamless copying
- Generated signatures use HTML tables for maximum email client compatibility

## 🌟 Why HTML Tables?

Email clients don't support modern CSS like regular browsers. HTML tables ensure your signature looks great in Gmail, Outlook, Apple Mail, and other clients.

## 💡 Tips

- Keep your signature concise - aim for 4-6 lines max
- Only add social links that are professionally relevant
- Test by sending an email to yourself
- Some email clients may strip certain styles - the generator uses safe, compatible HTML
